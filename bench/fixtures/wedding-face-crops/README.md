## Why LFW-only

The plan originally recommended 5 LFW + 3 consenting team identities for distribution coverage. We chose LFW-only for v1, accepting that thresholds will be tighter than amateur event photos require (biasing toward false negatives, the safer error mode). Phase 4 retuning on real beta data will fill the gap. See `docs/ops/threshold-decision-2026-04.md`.
