# Synthetic seed fixtures

No real person is depicted. They exist only to validate that the
benchmark pipeline runs end-to-end.

Category labels (single_frontal, dim_light, low_res, group_shot)
describe how this seed script processed the images, not real-world
photo characteristics. Replace with real event photos before drawing
any threshold conclusions.
